# AGENTS.md

Guidance for AI coding agents working in this repository.

## Project Overview

CpE211 Lab 5 — a menu-driven, plain-Java console program that implements an array-backed **stack (LIFO)** and a **circular queue (FIFO)**, demonstrated through an Undo simulation and a customer-service queue, with a built-in self-checking test script (T1–T5) that prints PASS/FAIL evidence.

## Build & Run

```bash
javac Lab5.java
java Lab5
```

- Requires JDK 8 or newer (verified on JDK 25). No external dependencies, no build tool (Maven/Gradle) — plain `javac`/`java` only.
- `Lab5.class`, `ArrayStack.class`, `ArrayQueue.class` are compiled artifacts regenerated by `javac`; do not hand-edit or worry about them being stale after recompiling.

## Verification

The project's test suite is built into the program:

- Run `java Lab5`, choose menu option `[9] Run test script (T1-T5)`.
- Success is signaled by the final line `ALL TESTS PASSED`; any `FAIL - ...` line indicates a regression.
- Always run the test script after modifying `Lab5.java` and report the result.

## Source Layout

All code lives in a single file, `Lab5.java`, containing three classes:

| Class | Purpose |
|-------|---------|
| `Lab5` (the only `public` class) | `main()` menu loop, input handling, and `runTests()` (T1–T5) |
| `ArrayStack` | Fixed-capacity LIFO stack: `push`, `pop`, `peek`, `isEmpty`, `isFull`, `display` |
| `ArrayQueue` | Fixed-capacity circular FIFO queue: `enqueue`, `dequeue`, `peek`, `isEmpty`, `isFull`, `display` |

## Conventions (must follow when editing)

- **Single file**: keep all three classes in `Lab5.java`. Only `Lab5` may be `public`; `ArrayStack` and `ArrayQueue` are package-private top-level classes.
- **Capacity**: `CAPACITY` (currently 5) is the single size constant at the top of `Lab5`. The T1–T5 tests assume a capacity of 5 (fill-to-capacity and wrap cases) — if you change it, update the test expectations to match.
- **Error handling**: never throw on overflow/underflow. Overflow is rejected with a printed message and no state change; underflow prints a warning and returns the `-1` sentinel value.
- **State guards**: every mutating operation (`push`, `pop`, `enqueue`, `dequeue`, `peek`) checks `isEmpty()`/`isFull()` first.
- **Circular queue invariants**: wrap indices with `(index + 1) % capacity`; `count` (not index comparison) distinguishes full from empty; `display()` must walk the logical order from `front` using modular arithmetic.
- **Stack invariants**: `top` starts at `-1`; `push` increments before storing, `pop` reads before decrementing.
- **Input handling**: menu input uses `Scanner` with `hasNextInt()` guards; invalid tokens are consumed and re-prompted — keep this pattern.
- **Style**: plain Java SE 8, standard library only (`java.util.Scanner`), no external dependencies, no comments in code, output strings match existing wording/format where behavior is asserted by tests.
